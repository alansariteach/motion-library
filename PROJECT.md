# Motion Library: project handoff (for Claude sessions)

Owner: Ali Alansari (Alansari.Tech). Language: Gulf Arabic. Standing rule: review your own work and fix errors immediately without asking.

## What it is
Single-file site of 1000 named motions (M-001..M-1000; 275 base + 725 variants Fast/Slow/Gold/Boxed) and 123 fonts (FA-xx Arabic, FE-xx English). AR/EN toggle, example video per motion, Fonts tab (with all-fonts zip download). The library file for AI is distributed through the plugin only: the site has no download buttons for it (removed 2026-10-20, the page box now explains the plugin install).

## Where things live
- Site repo: github.com/alansariteach/motion-library (GitHub Pages: https://alansariteach.github.io/motion-library/). `index.html` is the source of truth. `examples/M-xxx.mp4` (1000 videos), `fonts/` (arabic/, english/, alansari-fonts.zip), `lib/` (per-category library files + INDEX.md, generated), `alansari-motion-library*.md/.json` (generated), `tools/` (renderer and scripts).
- Plugin repo: github.com/alansariteach/alansari-plugins (marketplace `alansari-plugins`, plugin `alansari-motion`, skill `alansari-motion-library` with bundled copy in `references/`). Users add it in claude.ai: Customize > Plugins > Add > Add marketplace > Add from a repository, then Sync automatically.
- The user also has a personal Skill `alansari-motion-library` that reads `lib/INDEX.md` then one category file.

## How to change things
1. Edit `index.html` (M[] entries, CSS, UI strings). Test with Playwright (file:// + --allow-file-access-from-files).
2. Run `tools/build_lib.py` (regenerates md/json/lib). Copy the md/json to the plugin repo `references/`, bump `version` in plugin.json and marketplace.json, commit and push both repos.
3. Re-render only changed examples: `python3 tools/exrender.py M-001,M-002` (needs fonts Alexandria, Changa, Space Mono, Orbitron installed in ~/.fonts; assets in tools/assets; clip frames fa/ fb/ are extracted from the user's two video clips with ffmpeg at 540x960 30fps, 226 frames each; paths inside exrender.py point to /home/claude/demo). Then copy mp4 into `examples/`.
4. Check with `tools/sheet.py` (contact sheets) and `tools/audit.py` (static-video check). Known intentionally near-static: Face Blur, Halftone, Watermark Corner, Label Follow, Callout Line.
5. Commit trailer: Co-Authored-By + Claude-Session lines. Pages takes 2-5 min to update.

## Gotchas
- Keep `buildMD()` / `buildJSON()` in `index.html`: `tools/build_lib.py` calls them through Playwright to generate the library files, even though the site no longer offers them as downloads.
- Class names collide easily in index.html (e.g. `.fcard` is a card-flip motion; fonts use `.fnt`). Grep before adding CSS.
- The live library file is large; fetch tools truncate it. Always read `lib/INDEX.md` then one small category file.
- Python string edits (not sed) for index.html. Google Fonts is blocked in the sandbox, so fonts are installed locally.

## Footage effects in the Studio (2026-11-21)
- `tools/studio/fx.js` (`FX`, concatenated before studio.js by build_studio) draws every camera, transition, person and time motion (`CAM/TRN/PER/TIM`, 277 with variants) on the real video, in the live preview (`#fxc` canvas between the `<video>` and `#ovl`) and in the MP4 export (same `FX.draw`). Extra ids treated the same way: M-074, M-076, M-146, M-148, M-154, M-155, M-156, M-217, M-218, M-219, M-233, M-243, M-251.
- A footage clip is the whole effect: its default length is `FX.dur(m)` (nominal × `vf` for fast/slow variants) and progress = time in clip / clip length; gold variants use #FFC857 as accent, otherwise the clip palette. The clip's x/y (the dashed circle on the video) is the focus point (zoom centre, where a reveal starts).
- Person cut-out: MediaPipe tasks-vision 0.10.21 from jsDelivr with `vendor/selfie_segmenter.tflite` (in the repo), GPU delegate with CPU fallback, 256-px input, cached per frame; also gives the head position. Loaded only when a person/tracking motion is used («قاعد أجهّز قص الشخص…»).
- Text behind the person (M-201 family) keeps its editable title as HTML; the person is drawn again in a `.sd-fxp` canvas placed right after that clip in `#ovl` (preview) and between two `XR.snap` passes (export), so captions above it stay in front. Pop-out frame does the same inside the canvas.
- Transitions use a still of the moment just before the clip (or the start of a deleted part when the clip sits on a cut, `FX.holdTime`) as the outgoing shot, grabbed with a second hidden video (`grab()`); adding a transition near a cut snaps it to the cut.
- Time effects remap the source time (`FX.remap`: reverse, boomerang, stop motion, fast forward, rewind, slow motion); the preview shows remapped frames through the hidden video, the export seeks the main video; audio is unchanged.
- Tracking motions (TRK + M-160, not M-245/M-248) follow the real face: the motion's drawn face position/size (`TRKA`, default 53.5% down, 26% wide in the 4:5 stage) is lined up with the detected head every frame; dragging by hand turns it off (`c.trk=0`), the inspector has «🎯 تتبع وجهي تلقائياً». The demo yellow ball `.obj` and its path animation are hidden in the Studio.
- Test footage used here: MediaPipe's portrait sample made into a 9:16 clip; contact sheets of every effect were checked by eye.
- Multi-select (2026-11-22): `msel` beside `sel`; Shift/Ctrl/⌘ + click (timeline block or on the video) adds/removes, drawing a box on an empty part of a motion lane (`.sd-rband`) selects what it touches, Ctrl+A selects all, Esc clears, «☑️ حدد الكل» and «📝 حدد كل الكابشن» buttons in the timeline bar (the caption one shows only when captions exist; also in a caption's inspector). Dragging any selected motion on the video or on the timeline moves the whole group; the inspector (`inspMulti`) moves X/Y/size by the same amount for all, nudges up/down/earlier/later, sets one font/palette for all, deletes all. Note: `.sd-box` is the modal box class, do not reuse it.
- Caption look picker (2026-11-22): the captions window shows every look as live tiles drawn with the user's own words: the 16 ready styles CS-xx, then every motion of the captions section (CAP, with variants); a «اكتب رقم الحركة» box takes `86`, `M-086`, `CS-02`…, selects and scrolls to it; the chosen tile is outlined and marked ✓, remembered in `ml-capsty`; optional font and palette override (`capPlace(text,id,n,pos,font,pal)` accepts a CS id or an M id).
- Several videos (2026-11-22): `SRC[]` = uploaded videos in order (`{f,name,url,dur,w,h,el,off}`), one `<video>` each inside `#frame` (only `.on` is visible; others `opacity:0` so they still decode). `VP` is a facade used as `vid` everywhere: `currentTime` is timeline time and switches videos, `VP.el` is the current `<video>` (use it for drawImage/FX), `VP.tick()` steps into the next video at a join while playing (not during export). The frame size is the first uploaded video's; other shapes are letterboxed (`FX.full`/`FX.fit`). Upload several at once (`#vfile multiple`) or «➕ أضف فيديو» / the ＋ at the end of the video track (`#vfile2`). Joins split the video track into parts (`joins()` in `segList`), each join (and the end of every deleted part) has a yellow ✦ that opens `trnPick(T)`: all 104 transitions drawn live, number box, ✓ on the one already there, remove; transitions treat joins like cuts (`cutsJ()` → `FX.holdTime`), so the outgoing shot is the last frame of the previous video. Audio for export, captions and silence cutting is `decodeAll(ctx,chans)` (every file decoded and placed at its offset). The inspector (nothing selected) lists the videos with ⬆ ⬇ 🗑 (`srcMove`/`srcDel` move motions, cuts and splits with their own video).

## Layers, free tracks, export quality (2026-11-22)
- Overlay videos ("layers") are clips with `m:'__VID'` (VIDM pseudo-motion); files live in `OVF[u]={f,url,dur}`. Drawn in export by `ovDraw`, mixed in audio by `ovMix`, inspector `inspOv`.
